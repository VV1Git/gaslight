    Tips

    • Several accounts: switch to the right account on Reddit before you press Post. The "Post as" field on each draft reminds you which one.
    • Old vs new Reddit: "Open" uses old.reddit.com, which fills in title and body reliably. If you prefer the new site, use "New Reddit". If something doesn't fill in, use the Copy buttons.
    • Phone: if links open the Reddit app, long-press and choose "open in browser".
